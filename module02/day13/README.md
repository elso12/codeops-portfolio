# Kazanchis Pharmacy Profile Card

A styled one-page profile card for a fictional Addis Ababa business.

## Business
**Kazanchis Pharmacy** — serving the Kazanchis community with prescriptions, wellness products, and TeleBirr payments.

## CSS Techniques Used
- `:root` palette and spacing scale with CSS variables (`var()`).
- Global `box-sizing: border-box`.
- Google Fonts (`Inter` for body, `Playfair Display` for heading).
- Centered card with padding, border, border-radius, margin, and box-shadow.
- Clear typographic hierarchy: business name, tagline, body text.
- "Contact" button with hover state using HSL lightness change.
- Decorative `::before` pseudo-element accent above the card.
