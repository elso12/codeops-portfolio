# Habesha Market - Ethiopian Marketplace

Welcome to **Habesha Market**, an online marketplace platform bringing authentic Ethiopian products—including single-origin coffee, handcrafted textiles, traditional spices, and cultural crafts—to customers worldwide.

This project is built across **Module 2**, progressing through semantic HTML markup, modern CSS styling, and interactive JavaScript features.
