# 🍽️ Habesha Eatery - Modern Restaurant Website

A responsive, elegant, and modern web interface designed for an Ethiopian restaurant. This project showcases a mobile-first approach, modern CSS layouts (Grid and Flexbox), and polished typography to deliver a premium user experience.

## ✨ Features

- **Mobile-First Design:** Fully responsive layout that scales beautifully from smartphones to large desktop screens.
- **Modern Typography:** Integrated with Google Fonts (`Playfair Display` for elegant headings and `Inter` for highly readable body text).
- **Advanced CSS Layouts:** Utilizes CSS Grid for the menu cards and Flexbox for precise alignment of headers and navigation.
- **Interactive UI:** Smooth hover states, subtle box shadows, and transitions that enhance interactivity without being overwhelming.
- **Accessibility Considered:** Includes `@media (prefers-reduced-motion)` guards to disable animations for users who prefer reduced motion, and utilizes semantic HTML tags (`<header>`, `<main>`, `<article>`, `<section>`).

## 🛠️ Technologies Used

- **HTML5:** Semantic markup for better accessibility and SEO.
- **CSS3:** Custom properties (variables) for consistent theming, Grid, Flexbox, and modern pseudo-classes.
- **Google Fonts:** External typography integration.
