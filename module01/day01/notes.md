### Terminal Commands
1. cd: Changes the current directory.
2. mkdir: Creates a new directory/folder.
3. ls: Lists the files in the current directory.
4. echo: Prints text to the terminal or writes it to a file.
5. pwd: Shows the current directory path you are in.

### Git Commands
1. git init: Starts a brand new Git repository in the current folder.
2. git add: Stages changed files so they are ready to be committed.
3. git commit: Saves a snapshot of your staged files with a descriptive message.
