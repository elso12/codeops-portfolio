# Addis Eats - React Frontend

A modern, interactive restaurant menu and cart application built with React and Vite. This project demonstrates core React principles including component composition, unidirectional data flow, and state management.

## 🚀 Features

- **Component Architecture:** Modular UI built with distinct, reusable functional components (`Header`, `Dish`, `Sidebar`, `Footer`).
- **Dynamic Data Rendering:** Menu items are rendered dynamically from a structured JSON dataset using `.map()` and unique keys.
- **Interactive Cart State:** Uses React's `useState` to manage a real-time shopping cart. Users can add items, decrease quantities, and automatically calculate total prices.
- **Controlled Forms:** The checkout form captures user input (name and phone number) via controlled state variables, managing submission events natively.
- **Responsive Layout:** Styled with vanilla CSS utilizing CSS Grid and Flexbox for a clean, responsive layout.

## 🛠️ Tech Stack

- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** CSS3 (Variables, Flexbox, Grid)
- **Deployment:** Vercel (CI/CD)
